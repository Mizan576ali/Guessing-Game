# 🎯 Number Guessing Game

A Java-based Command-Line Interface (CLI) Number Guessing Game where the player tries to guess a randomly generated number.

## 🎮 Features

- Three difficulty levels:
    - Easy — 10 attempts
    - Medium — 5 attempts
    - Hard — 3 attempts
- Random number generation
- Time tracking
- Best score tracking
- Multiple rounds
- Option to reveal the computer's selected number
- Difficulty selection using Java `enum`
- Command-line interface
